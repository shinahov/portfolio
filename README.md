# Ibragim Shinakhov — Portfolio

Personal portfolio in the style of a retro desktop.

**Live:** https://shinahov.github.io/portfolio/

## Structure

| Path | Content |
|---|---|
| `index.html`, `*.js`, `*.css` | the site |
| `images/`, `cv/` | images and CV |
| `worker/` | Cloudflare Worker: contact form → Telegram |
| `classic/` | previous version |

## Run locally

Open `index.html` in a browser. The contact form only sends from the live site.

Built with the help of AI (Claude, Codex).
